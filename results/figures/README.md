## Figure Requirements

Before uploading a figure, check that:

- [ ] The title clearly explains what is shown
- [ ] Both axes include names and units
- [ ] The text is easy to read
- [ ] Measured and fitted curves are clearly identified
- [ ] A legend is included when needed
- [ ] The figure matches the final MATLAB results
- [ ] The filename clearly describes the figure
- [ ] No duplicate or outdated version is uploaded

---

## Upload Rules

- Upload final figures as PNG files.
- Use the planned filenames unless the team approves a change.
- Do not upload several copies named `final`, `final2`, or similar names.
- Update the existing file when a corrected version is created.
- Record calculation or modeling corrections in `documentation/validation.md`.
