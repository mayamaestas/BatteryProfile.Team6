## Summary Results Table

The final summary table should include:

- Selected battery cycle
- Charging interval
- Fitted `tau`
- R-squared
- RMSE
- Time to 80 percent charge
- Practical full-charge time
- Delivered energy in joules and watt-hours
- Internal-resistance value
- Resistive energy loss in joules and watt-hours

The final values must match the MATLAB output and `documentation/validation.md`.

## Model Comparison Table

The model-comparison table will only be included if the team decides to keep the optional models.

It may compare:

- Required fixed 3.6 V model
- Shifted one-time-constant model
- Two-time-constant model
- Fitted parameters
- R-squared
- RMSE
- Final team decision
